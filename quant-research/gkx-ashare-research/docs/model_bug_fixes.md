# 模型与评价修订记录

作者：Gilmour Jia。Codex 辅助代码检查与修订；此记录不是外部独立审稿认证。

## 已修订、已针对性验证

| 项目 | 原问题 | 修订行为 |
|---|---|---|
| 目标月切分 | 以特征月份切分，2018-12 特征的 2019-01 收益会进入训练期 | 统一按 `label_month` 切分；要求它恰为特征月的下一个自然月 |
| 旧标签误用 | 旧 `features_monthly.csv` 可混入缩尾收益和跨缺月标签 | 新 runner 要求修订 builder 的 `label_month/eligible_asof/market_cap` 字段；不接受旧缓存直接冒充修订数据 |
| 横截面排序 | v3 和旧组合代码使用 `rank(pct=True)`，与声明的 `2*rank/(n+1)-1` 不一致；部分代码先剔除未来标签缺失行 | 统一公式；先用当时合格样本排名，再按标签可用性拟合和计分 |
| 行业编码 | 用全部时期统计行业类别和小行业阈值；v1 用当前行业快照 | 只在训练样本学习词表和阈值；后续未知类别归 OTHER；启用行业项时必须有历史月度表 |
| R² 基准名称 | 测试集均值分母被称为“训练历史均值”；逐月平均 R² 被称为论文主口径 | 分开输出 pooled zero benchmark、evaluation-sample mean、training-sample mean 和 equal-month average；前三者不混称 |
| RF/GBRT 参数记录 | 调用方读取不存在的 `best` 键，日志出现 None | 返回并落盘真实 depth/max_features/lr/trees/leaf/seed |
| PCR 秩亏 | 奇异值为零或数值接近零时仍做除法 | 根据数值秩限制候选成分；全常数矩阵返回训练均值 |
| NN 验证目标 | 以两种子单模型 MSE 的平均选择配置，实际交付却是平均预测集成 | 用两种子平均预测的 MSE 选配置；输出调参种子、最终种子、每个网络最佳 epoch |
| NN 失败输入 | 空样本、非有限输入、零 epoch 可在取最佳权重时异常 | 提前验证并明确报错；没有有限验证结果时失败退出 |
| Huber GLM 权重 | 对 X 乘 w，未对 y 同步加权，且继续假设加权后组内 Gram 为单位阵 | X 和 y 同时乘 sqrt(w)，按加权块的 Lipschitz 常数做近端更新；单组零惩罚测试与独立加权最小二乘参考相符 |
| 最大回撤 | 财富曲线未包括初始净值 1，漏掉第一期亏损 | 计算回撤时加入初始净值 |
| 年化和夏普表述 | `(1+平均月收益)^12-1` 被作实际年化；总收益均值/波动率未扣无风险收益却直接叫夏普 | 输出复利 CAGR；总收益比率明确标为假设 rf=0 的年化均值/波动率，跨缺失月不输出连续策略 CAGR |
| 分组相同预测 | 常数预测或大量并列时可能把少于十组称为十分位 | 无法形成完整十组时跳过并披露样本缺失 |
| 常数预测的相关系数 | `std()==0` 对完全相同的小数有时受浮点残差影响，导致常数月出现伪相关数值 | 先用精确极差判断常数，再计算相关系数；汇总分别报告两种相关系数的有效月份数 |
| 结果可追溯性 | 多轮结果口径、代码和参数可混淆 | 每次新 tag 输出指标、预测明细和来源/代码 SHA-256、库版本、时段及 seed manifest；已有 tag 拒绝覆盖 |
| 蒙特卡洛多期限切分 | h>1 时先加和未来 h 期收益再按形成期三切，训练与验证、验证与测试的标签共用冲击 | 对 train 和 valid 尾部各移除 h−1 个形成期，确保标签使用的收益期不交叠；h=1 保持原切分；新输出带 split_protocol，拒绝续接旧未隔离记录 |
| A3/A4重复计数 | A3用方法组l1/glm检查已完成的Lasso/ENet/GLM记录，续跑不能正确跳过；A3/A4默认追加已有文件，可能重复计数 | A3展开组名后按(seed,method)跳过，拒绝重复/损坏/旧版本记录并绑定配置和源码；A3非resume、A4已有tag均拒绝隐式追加 |

## 运行接口

三个 `run_ashare*.py` 入口现在共用同一实现，默认使用修订后的 19 个价格、交易与股本特征。旧 v2/v3 文件名保留用于定位历史；旧的默认特征集合不再隐式启用。

- `GKX_DATA_DIR`：本地原始输入位置。
- `GKX_DERIVED_DIR`：修订后的派生特征位置，优先于 `GKX_DATA_DIR`。
- `GKX_CLEAN_DIR`：历史行业表位置，只有显式 `--industry` 才需要。
- `GKX_OUT_DIR`：本轮新输出位置；默认 `out_repaired`。
- `--chars 28|71|fund56 --allow-unverified-features`：明确探索性财务实验。由于历史缓存中的未来信息问题，已知危险特征仍会排除，不能把这个开关理解为验证通过。
- `--macro --allow-unverified-features`：探索性宏观交互；财务 vintage 风险随输入继承。

测试集的默认目标收益月份为 2022-01 至 2025-12，对应形成月份 2021-12 至 2025-11；历史实验按形成月份分割得到的 47 个月结果不能直接与之相减归因。

## 验证范围

`tests/test_model_evaluation.py` 共 11 项针对性测试通过，覆盖 R² 不同基准及向量维度、标签跨界、重复合并拒绝、排序公式、训练行业词表、秩亏 PCR、树模型 seed/参数、NN 重复性、Huber GLM 加权参考、初始回撤和常数预测分组。

`tests/test_model_horizon.py` 另有 3 项测试通过：h=1 原切分不变，h=3/6/12 跨集合的标签收益期无重叠，构建设计矩阵时各期限按明确的收益加和规则生成。多期限修订是本项目的防泄漏协议，不宣称已经核对为原论文唯一实现。

`tests/test_model_summary.py` 另有 4 项测试通过：拒绝错配标签、缺失或重复 stock-month 键；用小型手算例验证 pooled R² 是平方和之比，不能换成月 R² 的平均；检查小数常数预测的相关系数缺失及有效月份统计。

`tests/test_simulation_records.py` 另有2项，覆盖A3重复键/配置不一致拒绝及A3/A4已有记录防追加。模型与评价测试共20项，连同16项数据测试，最终联合测试为**36项**。A3/A4历史聚合值未因代码修订被重写；缺少逐次原始记录的历史表无法追溯判定是否受到重复追加影响，需新tag重跑。

`scripts/run_smoke.py --nn` 已在合成数据上跑通 Ridge、RF、GBRT、NN1。合成结果仅验证工程链路，不是 A 股表现，也不构成完整 GKX 复现验证。

## 本轮真实数据执行记录

已完成同一修订 price19 输入上的 9 个模型：OLS、Ridge、Lasso、ENet、PCR、PLS、RF、GBRT、NN3。两次执行只因计算顺序拆分 tag，并未改变样本、特征或核心代码；文件中的源码 SHA-256 和输入 SHA-256 相同。共有 178,488 个训练、119,719 个验证和 212,293 个测试股票月，测试覆盖 48 个目标月。

| 模型 | pooled zero-benchmark OOS R²（%） |
|---|---:|
| OLS | 1.067898 |
| Ridge | 1.090155 |
| Lasso | 0.874013 |
| ENet | 0.738241 |
| PCR | 0.759130 |
| PLS | 1.142372 |
| RF | 0.725349 |
| GBRT | 0.148764 |
| NN3 | 0.886238 |

这不是模型优劣的显著性结论。PLS 的误差指标较好，Ridge 的平均月 Rank IC 约 0.1394（48/48个月有效）。GBRT在47/48个月的截面预测完全相同，IC和Rank IC均未定义；唯一有效月份2025-05的Pearson IC为−0.1562、Rank IC为−0.1014，不能解释为48个月持续负排序。该结果说明正零基准R²本身不保证存在可用于股票排序的截面变化。训练均值基准的 GBRT R² 为 −0.4920%。

本轮 RF/GBRT 均使用 100 棵树、最小叶节点 100；完整候选网格见绑定的 `run_ashare.py`。NN3 采用 λ={1e−5,1e−4,1e−3}、lr={0.01,0.1} 网格，每配置调参种子 0/1；选择 λ=0.001、lr=0.1，最终集成种子 100/101/102。每个网络最多 60 epoch、patience=5，三个网络的最佳 epoch 都为 2。**未保存每个候选配置的验证 MSE，也未保存逐 epoch 轨迹；不能从最佳配置反推这些未记录信息。** 本轮没有重跑 NN1—NN5 全架构比较。

`scripts/summarize_predictions.py` 对两份预测按 code/month/label_month 严格 1:1 合并，并逐项确认真实收益和市值完全相同。公开导出只含每月模型样本数、SSE、Σy²、R²、Pearson IC、Spearman Rank IC；逐股预测保留本地。9 个模型重算 pooled R² 与原指标 CSV 最大偏差为 2.22×10⁻¹⁴ 个百分点。

Ridge 与 NN3 另完成 48 个月的等权十分位毛收益诊断；代码显式保留 rf=0、交易成本/融券/成交机制未建模等限定，不能称为可执行净收益策略。

## 未解决与解释边界

1. 原始数据的退市覆盖、配股及复权事件、事后修订财报和历史股本可得性并未全部独立核验。价格特征版本的代码修订不等于所有原始数据已可信。
2. 财报 vintage 无法凭当前快照完整恢复。已知未来分红、年度行业聚合等缓存特征不进入默认基线；扩展实验必须单独标记风险。
3. 本轮默认标签仍是总收益，尚未接入逐月无风险利率。不能将 R² 与 GKX 超额收益口径直接比较。
4. 固定训练/验证/测试切分不是 GKX 的年度重新估计；多年研究已反复查看该测试期，它不是全新未触碰留出集。
5. 组合仍是毛收益排序诊断，未完成买卖执行、涨跌停成交、融券、成本、容量与完整换手率模型；多空差不能等同实盘账户收益。
6. Huber OLS/Ridge/ENet/GLM 中的稳健阈值和固定训练均值截距、样条规范仍属于本项目实现选择；本次有限测试不证明全部蒙特卡洛结果与 GKX 附录数值一致。尤其 GLM 标准化正交基惩罚不等于任意原始基上的相同 λ 惩罚。
7. 历史 NN3 的 1.0177%（约 1.02%）应作为原版本探索性记录保留，不能自动冠以本次修订后已验证结果。完整实证重跑、不同 seed、分组与滚动检验另列任务。
