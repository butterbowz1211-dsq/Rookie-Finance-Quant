## Data Availability

The historical aggregate results supporting the reported Monte Carlo experiments and exploratory A-share model comparisons are provided in `results/historical/`, with file-level provenance and SHA-256 checksums in `results/historical/manifest.json`. These files document historical experiments and are not presented as results regenerated by the repaired code. A claim-level evidence map is provided in `docs/claims_inventory.json` and `docs/evidence_inventory.md`.

New aggregate results from the repaired 19-feature experiment are provided separately in `results/repaired/`. Two model-result tables and their run manifests cover nine estimators on a shared sample of 510,500 labelled stock-month observations, including 212,293 test observations across 48 target months (January 2022–December 2025). `results/repaired/monthly_summary/` contains monthly squared-error sums, squared-return sums, R² and IC/Rank IC, together with recomputed pooled metrics, explicit valid-month counts for each correlation measure, and an aggregation manifest. GBRT has only one valid IC/Rank IC month out of 48 because its forecasts are constant across stocks in the other 47 months; the corresponding single-month correlations do not establish stable ranking performance. Gross equal-weight portfolio series and diagnostics for Ridge and NN3 are provided in `results/repaired/ridge_portfolio/` and `results/repaired/nn3_portfolio/`. `frozen_build.json` and `replay_comparison.json` document the frozen feature-build hashes and byte-identical replay of the model input. These checks establish the stated computational bindings; they do not establish correctness or completeness of the third-party market data. Detailed methods, environments, results and unresolved limitations are reported in `docs/repaired_results.md`.

The underlying stock-level prices, corporate actions, financial statements, share-capital records, and security-status and industry histories were obtained from third-party public-facing services, principally Sina Finance, East Money, and CNINFO. Public accessibility of these services does not establish permission to redistribute their underlying datasets. The repository therefore does not redistribute the downloaded raw market data, full processed stock-level panels, or historical stock-level model predictions. Users must obtain the required data directly from the relevant providers under the applicable terms. The source locations, required fields, processing scripts, and known coverage limitations are documented below and in the research methods. Historical revisions, incomplete delisted-stock coverage, and unverified data vintages limit exact reconstruction of the historical empirical results.

Synthetic data for the Monte Carlo experiments are generated by the supplied DGP code. No DOI or permanent dataset accession has been assigned to this project. Git commit and release identifiers should be used to identify the exact version being inspected; any later archival DOI must be added only after the archive exists.

The final package also provides aggregate pre-ranking missingness counts for 19 features in three sample partitions in `results/repaired/feature_missingness/`, and an input-coverage audit in `results/repaired/entry_gate_audit.json`. These contain no raw return observations. A byte-exact copy of the feature builder used in the recorded run is preserved in `results/repaired/executed_source/`; `source_annotation_revision.json` documents the later module-documentation-only change and equality of the executable abstract syntax trees. Frozen run hashes continue to identify the executed version.

## Code Availability

The author-supplied research code and the documented revisions are maintained with this repository. The author is Gilmour Jia. Code for data acquisition, preprocessing, model estimation, evaluation, and synthetic-data simulation is located under `research/ML金融学习计划/`; executable checks and their results are documented separately, including 36 passing checks in `docs/test_log.txt`. Source-code availability and these checks do not establish that every historical experiment can be reproduced from the current code. See the evidence inventory and repaired-results report for the separation between historical outputs, newly executed 19-feature experiments, and experiments that remain to be rerun. Feature construction and model estimation used distinct dependency environments, recorded in the corresponding manifests; the raw third-party inputs and complete stock-level predictions are not redistributed. The repository's actual licence file, if present, governs use of the author's code and does not grant rights over third-party source data.

## 3. 仓库和引用操作

1. 发布时使用实际仓库地址及提交 SHA 更新主 README 和引用元数据；不存在的 DOI、版本号或许可证不得预填。
2. 对未来重跑保留配置、代码提交、依赖版本、原始资产哈希和取数时间，生成每次实验的 run manifest。
3. 发布代码、聚合结果及合成检查；数据下载目录、逐股面板、缓存和密钥由 `.gitignore` 排除，并对最终待提交文件逐项核查。
4. 若后续取得再分发授权，单独形成数据版本，明确授权范围和数据许可证；软件许可不能覆盖第三方数据。
5. GitHub 是版本化访问入口，尚不等于长期数据存档。需要论文正式引用时，再选择可归档 release 的长期仓储并取得真实持久标识。
