## 已修复的实现问题

| 问题 | 原实现与影响 | 修订方式 | 验证边界 |
|---|---|---|---|
| 全样本收益缩尾 | `screen_returns.py` 用整个样本 1%/99% 分位截断 `ret`，后续标签和部分收益特征继承这些阈值 | `ret` 始终保留原值；可选缩尾须指定训练期，单独写 `ret_train`，测试期该列为空 | 阈值不受测试收益扰动，16 项测试中的相关用例通过；真实极端值仍需源数据核验 |
| 未来月份筛选影响标签 | 旧 `returns_clean.csv` 删除低交易日月份，然后作下一行标签 | 屏蔽条件成为特征月 `eligible_asof`；原始收益保留供精确标签匹配 | 不因为下个月交易天数少就删除已经发生的损益；完整成交模拟仍未实现 |
| 跨缺失月的预测目标 | `groupby.shift(-1)` 把下一个有记录月份当成下月 | 生成 `label_month=t+1`，按 `(code,label_month)` 精确匹配；缺失仍为 NaN | 合成缺月、重复键测试通过 |

| 用未来总覆盖长度筛样本 | 全样本每股行数达到 `min-months` 就保留其最早记录 | 改为截至特征月的历史观测数达到阈值 | 不使用未来是否继续有行情来判断当前资格；股票初始来源的幸存者偏差仍未解决 |
| 除权日污染日频风险特征 | 未复权收盘价直接 `pct_change`，除权缺口进入 maxret/retvol/ill | 用既有现金派息、送转调整函数计算日总收益后聚合 | 送转除权合成案例通过；配股、重复方案、缺失除权记录仍需审计 |
| beta 归一化不一致 | 样本协方差 `ddof=1` 除以总体方差 `ddof=0` | 两者统一 `ddof=0`，残差含截距 | 人工线性模型斜率 2 被准确还原 |
| 变换后规模充当市值 | 从可能已缩尾的 `mvel1` 取指数重建市值 | 单独保留原始 `market_cap`；财务和宏观模块必须使用该列 | 缺少原始市值时拒绝执行；股本历史信息本身仍需核验 |
| 财报同比跨缺季度 | `shift(4)` 假设每个代码每季度都有记录 | 按精确财政季度键取四季度前值，缺期保持缺失 | 缺季度单元测试通过 |
| 不完整 TTM 被替换为 YTD | 缺上一年年报或同期值时把当前累计数当 TTM | 缺依赖保持 NaN；依赖公告日期纳入可用日期上界 | 测试核对缺失依赖及晚披露年报；无法还原供应商未保存的原始版本 |
| 多表公告时间丢失 | 完整报表合并只保留先出现表的 `NOTICE_DATE` | 对合并组件使用保守的最晚已记录公告日期，跨期依赖也传播时间约束 | 更保守可能造成覆盖率下降，不等于财报 vintage 认证 |
| 年度行业聚合读取未来 | 静态行业、同报告年度全部季度共同计算行业中位数与集中度 | 先按保守公告日映射到月末，再用历史月度行业和该月可见特征计算中位数及 TTM 营收集中度 | 未来月份扰动不改变当月聚合；缺历史行业时结果缺失，不回退到静态行业 |
| 未来分红标志 | 报告年 Y 直接使用 Y+1 全年除权记录判断 divi/divo | 暂停这两个特征，生成值为 NaN | 待确定可复现的公告时点定义及历史记录后恢复 |
| 旧报告期市值分母 | 财报比率沿用报告期所在月市值 | `cashpr/rd_mve/bm_ia/cfp_ia/mve_ia` 在目标特征月使用该月原始市值重新计算 | 不改变财报可用日期约束 |
| 宏观缺失值加权 | 特征缺失的公司仍进入市值分母，拉低市场比率 | 每个变量分子与分母使用相同有效样本；收益组合使用前一自然月市值 | 缺失值权重回归测试通过 |
| V2 报告末尾崩溃 | 重命名 `SECURITY_CODE` 为 `code` 后仍访问旧列 | 汇总报告改用 `out.code` | 编译检查通过；完整财务批量运行尚未执行 |

`mom1m` 也从额外滞后一月改为特征月 t 已实现收益，以便预测 t+1。这个修改是与 GKX 短期反转时间口径的对齐，应在方法说明中披露。其他动量窗口及高低价差代理并未全部重构为原文定义。

## 原始数据与财报的明确边界

公告日期存在，不代表缓存中的金额就是当时首次披露的金额。两个财报 builder 因此默认拒绝生成；必须明确使用 `--allow-unverified-vintages` 才能生成**探索性**面板，并附 `point_in_time_certified=false` 的 manifest。该参数是承认数据边界，不是证明数据合格。

以下问题仍需补进项目：

- 以历史上市／退市名单建立逐月股票池，核对退市收益与缺失终止价格。
- 核验原始和更正财报版本，逐字段保留来源、披露日、抓取时间及适用的会计定义。
- 配股及停牌期间除权事件、分红记录去重、价格单位／成交量单位、股本变动可用日期的逐案核验。
- 财报若采用部分科目重建流动资产／流动负债，应明确其代理性质；`orgcap`、`tb`、`grltnoa`、`pchsaleinv` 等定义仍需逐项与原文对照。不能仅凭沿用缩写声称完成精确因子复现。
- 盈利改善连续期数、财务波动窗口等完整季度序列口径仍需单独经济定义测试。
- 回测的实际成交、停牌、涨跌停、交易成本、做空可得性，以及无风险利率口径。

## 路径与执行

`GKX_DATA_DIR` 是只读原始输入路径；`GKX_DERIVED_DIR` 是单独的修订产物路径；`GKX_CLEAN_DIR` 指向历史行业表目录。三个变量不应指向要公开的原始商业数据目录。不要将 `GKX_DERIVED_DIR` 设置成原始输入目录。

```powershell

python research/ML金融学习计划/D_A股数据/build_features.py --min-months 24 --min-days 10
# 仅在接受财报 vintage 未验证的研究边界时运行：

python research/ML金融学习计划/D_A股数据/build_fundamentals_v2.py --allow-unverified-vintages
```

验证记录：16 项数据层针对性测试通过，覆盖日除权、精确月标签、季度滞后、TTM 依赖、收益保留、训练缩尾、beta、缺失权重、raw 市值、行业聚合及 vintage 拒绝逻辑。该测试数不代表 16 项经济假说或原始数据均已验证。

## 仍保留的入口条件及本次影响核查

冻结构建器仍在逐股读取时跳过全文件日线记录少于60行的股票。这是一个全文件入口条件，不能把当前实现描述为所有股票池条件均只依赖形成日可得信息。对本次5,237个日线文件的只读核查发现，5,236只有匹配月收益；其中26只因该条件被跳过，只有2–54条日线，均覆盖2025年第四季度的1–3个月。它们在本次数据中能够满足“历史至少24个月、当月至少10日”的股票月为0，故没有直接排除合资格模型样本。

不过，特征缩尾发生在最终资格筛选之前，加入这26只仍可能改变2025年第四季度的截面缩尾阈值。不能据此宣称删除该条件后面板或模型预测必然不变。当前版保留实际执行的冻结源码和数值；下一轮应移除这一入口门槛、明确缩尾参考股票池，再从面板生成到模型估计完整重跑。本项属于未完成的时点隔离改进，不被36项测试或文件重放一致性覆盖。
