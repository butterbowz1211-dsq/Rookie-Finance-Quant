## 1. 结果状态与阅读顺序

本仓库将历史聚合结果保存在 `results/historical/`，新修订代码与历史输出分别标记。历史结果确有文件记录，不等于已经通过新代码和新数据重跑。`results/historical/manifest.json` 记录被复制文件的相对来源、SHA-256 和字节数；校验和证明复制内容一致，不能恢复旧运行时的全部代码、参数和环境。

本次已直接检查 A 股聚合 CSV、当前原始脚本、研究说明及导出的会话日志；对核心面板只读取代码和月份键核对规模。没有重新训练全部历史模型，也没有重新下载全部原始数据。下文的“已核实”限定为相应文件或代码确实存在。

## 2. 1.02% 的准确含义

| 字段 | 已查证内容 | 证据强度 |
|---|---|---|
| 文件 | `results/historical/ashare/ashare_v2_nn71.csv` | 原始聚合输出的逐字副本 |
| 模型 | NN3，三层隐层，32–16–8 | 输出模型名及 `nn.py` 的网络定义 |
| 输入 | 71 个公司特征与 81 个行业虚拟变量，共 152 列 | CSV 的 `n_feat=152`；当时说明的分解为 19 行情 + 9 财务 + 43 新增 |
| 目标 | 下一月总收益，历史 `ret_fwd` 来自旧收益清洗和特征面板 | 原始 `run_ashare2.py`、`build_features.py` |
| 样本内 R² | 2.6949173035446528% | CSV 的 `IS` |
| 验证 R² | 1.3848198837357661% | CSV 的 `valid` |
| 样本外 R² | **1.0177149183600132%，四舍五入为 1.02%** | CSV 的 `OOS` |
| 测试样本中心化 R² | 0.413772446082028% | CSV 的 `OOS_dm` |
| 选中超参数 | L1 惩罚 1e−4；学习率 0.1 | CSV 的 `param` |
| 集成 | 研究说明记载 3 个种子；当前入口固定 `seed=0`，调参种子为 0、1，最终集成种子由 `100+e` 生成 | 说明与当前代码相符，但没有完整历史运行清单来冻结该次随机种子、epoch 和代码版本 |
| 时间划分 | 特征月训练 2010-01—2018-12；验证 2019-01—2021-12；测试 2022-01—2025-11 | 当前旧入口的 `SPLIT`；分别为 257,218、138,507、232,388 行 |

这里的月份原本按特征月切分；若标签正确代表下一自然月，测试收益月份应相应为 2022-02—2025-12。旧标签存在缺月后跳到下一观测的风险，因而不能把这一“应当”作为旧数据逐行已通过的证明。修订版应同时记录特征月和目标月，并检查训练期最后一个标签在验证开始时是否已可得。

R² 定义为 `1 − sum((y − prediction)^2) / sum(y^2)`，零预测是比较基准。**1.02% 不是年化收益，不是收益预测准确率，也不表示模型解释了某个固定比例的截面排序。** 此处 `y` 是总收益，与 GKX 的超额收益目标不同，且旧标签使用了全样本阈值缩尾。不能据此直接宣称优于 GKX 的美国样本结果。

## 3. 必须分开的三个实验

| 实验 | 结果 | 应如何表述 |
|---|---|---|
| v2 NN3，152 列 | 样本外 R² 1.0177149% | 已记录的历史 NN3 成绩，受旧数据处理问题影响；修订后待重跑 |
| v3 Lasso，156 列 | 样本外 R² 1.0517%；验证 1.0331%；选中惩罚 0.0005；49 个非零系数 | 19 行情 + 56 财务 + 行业列的另一套实验；不能替代 NN3 的复现或反证其泄漏问题 |
| `portfolio_check.py` Ridge 组合 | 会话记录的等权十分位多空夏普约 2.41；月均约 2.93% | Ridge 的历史无成本排序组合；没有在该次输出目录找到对应完整、冻结的组合结果文件，证据层级低于上面两个 CSV；不是 NN3 策略收益 |

Ridge 组合日志还出现过截距修订前后 R² 改变而组合排序不变的记录，这可以作为“损失函数与排序绩效评价不同”的教学案例。由于旧组合也使用缩尾后的标签作为收益，它不能证明真实可交易净收益。A 股融券可得性、涨跌停、停牌、交易费用及换手均需单独落实。

## 4. 树模型：已完成的对照比单一冠军分数更有信息

以下均为历史测试 R²，单位为百分数，各行特征集和实现版本不同，不能解释成单一因素的因果效应。

| 历史设定 | RF | GBRT | 文件 |
|---|---:|---:|---|
| 19 个行情特征 | 0.2963593 | −0.9246525 | `ashare_trees.csv` |
| 19 行情 + 9 财务 | 0.5859499 | −0.3175973 | `ashare_fund.csv` |
| 71 公司特征 + 行业，全 153 列 | 0.5501074 | −1.4689274 | `ashare_v2_tree71.csv` |
| 152 列，RF 最小叶样本 100、100 棵树 | 0.5787500 | 未报告 | `ashare_v2_rf71_leaf100.csv` |

可以强调已经建立了特征扩展、正则化与树模型容量设置的比较路径。当前证据支持“树模型在这些历史设定下没有稳定超过正则化基准”，不足以支持“树模型在 A 股失效”“财务特征对线性模型必然是噪声”或“小盘风格变化是唯一原因”。尤其 RF 的叶规模实验同时改变了树数，需固定其他设定后重新比较。

## 5. 蒙特卡洛模块是独立的研究亮点

文稿可按六大机器学习家族组织：PLS、PCR、Elastic Net、RF、GBRT、NN；Ridge/Lasso 是正则化线性模型的补充比较，OLS/OLS3 是基线，Oracle 仅用于已知真模型的模拟，GLM/group lasso 是模拟扩展。家族数量、实现变体数量与实际已跑组合数量是三个不同概念。尤其 A 股历史聚合文件中的 NN3 不能被写成 A 股已经完整比较 NN1—NN5。

该模块重建 GKX Internet Appendix 的模拟设计，包含线性与非线性两种 DGP、50/100 个基础特征、训练/验证/测试切分、正则化/降维/树/神经网络及 Oracle 比较。不能与 A 股真实样本混在同一张性能排行榜。

已找到四个 DGP 格子的 Table A.1 线性、树和 NN 聚合文件，另有 GLM、Table A.3 变量选择频率、Table A.4 变量重要性、3/6/12 月期限结果。树和 NN 的主聚合文件记录每格每模型 `n=100`；GLM 和部分期限/敏感性实验重复次数不同，不能统一称全部 100 次。

例如线性 DGP (a)、Pc=50 的历史聚合结果：Ridge OOS 3.9697%、RF 3.6488%、GBRT 3.7470%、NN3 4.0974%、Oracle 5.5409%。非线性 DGP (b)、Pc=100 的 RF 为 3.2331%、GBRT 为 3.4236%，而 NN3 历史表现明显低于论文。报告应同时展示相符之处与偏离之处，不把“跑完”写作“精确复现成功”。

额外亮点是：有可执行 DGP、分片续跑和结果合并；将真实信号和噪声变量的重要性分开；识别深层 ReLU 网络的全零梯度/死亡网络；对 Huber 参数 API 含义、预测截距、维度病态作过诊断。这些工程与方法记录有公开复用价值。当前源代码已在多次运行之间变化；历史表不能自动归属于本次修订的代码。

## 6. 需要在新报告中纠正的旧文字

| 旧说法或比较 | 问题 | 新报告采用的边界 |
|---|---|---|
| A 股说明 §4 把 RF 3.35%、GBRT 3.35%、OLS 1.14% 当作美国实证对照 | 这些数字实际位于 GKX Internet Appendix **第 2 页 Table A.1**，表题明确是 simulations | 模拟与真实市场分别展示；美国月度实证应查主文 Table 1 |
| `R²_demeaned` 是“预测历史均值”的基准 | 旧代码使用测试样本自身均值，属于事后中心化分母 | 叫“测试样本中心化 R²”；若比较可实现历史均值预测，应另构建仅使用训练信息的基准预测序列 |
| “只有去均值 R² 反映排序能力”，或 RF 该值为负就“没有排序能力” | 平方误差与排序是不同对象；一个 pooled 去均值分母不等于逐月截面去均值 | 排序能力用按月 IC/Rank IC、分位组合及不确定性评价 |
| 最新 Lasso 1.052% 证明旧 NN3 1.02% 没有水分 | 模型、特征、代码版本同时改变；更高值也不能排除共同偏差 | 分版本列账；修复同一问题、保持比较条件一致后重跑 |
| 高维 OLS 极端负值一定是“不是算错的病态设计” | 实现错误、外推、稀疏行业、共线性等都可能参与 | 作为诊断对象，报告条件数、验证预测分布、正则化和实现检查 |
| A.2 只列 OLS、Oracle、GLM、RF、NN1 | 所取得附录 Table A.2 还包括 PCR、PLS、Lasso、Ridge、ENet、GBRT 等 | 重新逐表核对，避免把截取的部分行描述成原表全部模型 |

| 层级 | 当前可支持 | 仍需补充 |

| 修订实证再现 | 已完成19特征面板冻结重建、九模型共同样本估计、月度误差及Ridge/NN3毛收益诊断，见修订后结果 | 历史高维NN3/完整财务扩展尚未按相同条件重跑；新19特征结果不能替代旧实验身份 |
| 稳定性/经济意义 | 已有多个历史设定和组合探索 | 真正冻结的最终留出期、年度前推、月度依赖稳健推断、成本和可交易性 |

统计比较应以月份为时间序列单位，考虑截面共同冲击与序列依赖；不能把几十万股票月当作独立重复。测试期已经反复被查看，后续应将其称作被反复检验的历史样本，并另外建立冻结的新留出期。完整的补充实验计划应与报告分开维护，避免将计划写成已完成结果。
