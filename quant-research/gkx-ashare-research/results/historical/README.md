# Historical results / 历史结果

作者：Gilmour Jia。

这些聚合统计是修订前的历史研究输出，供审查和追溯。不得标注为本次修复后重跑结果。结果文件的存在和哈希一致不证明统计结论或原始数据已经通过完整性检查。

- `ashare/`：各轮 A 股模型比较 CSV。`OOS`、`IS`、`valid`、`*_dm`、`OOS_m` 均以百分数表示；1.02 表示 R²=1.02%，不是原始比例 1.02。`param`/`lam`/`alpha` 为模型原生超参数。
- `monte_carlo/`：主要模拟单元的聚合 CSV/JSON。`is_mean`、`oos_mean` 和其标准差以百分数表示；`n`（若存在）为重复次数。Table A.3 的 `six` 为 c1,c2,c3,c1×x,c2×x,c3×x 的入选频率，`noise` 为其他变量平均频率；Table A.4 相同排列为归一化重要性百分比，`noise` 是每个噪声变量的平均重要性。
- `manifest.json`：来源相对路径、字节数、SHA-256、字段和历史状态。原始会话与机器路径不进入公开包。

缺失值/空单元表示该文件未报告该字段，不作零处理。不同版本的特征维度、预处理、模型和计分可能变化，不能直接拼成同一公平比较。详细解释见 `../../docs/evidence_inventory.md` 与 `../../docs/claims_inventory.json`。

严格再现需要冻结代码、依赖、配置、原始数据版本及随机种子；当前历史资产并未完整具备这些条件。
