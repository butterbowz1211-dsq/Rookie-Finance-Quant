# 修订后实证结果

作者：Gilmour Jia

本目录为 2026-10-25 实际执行的新实验。它与 `../historical/` 中的历史结果保持独立身份。

| 文件/目录 | 内容 |
|---|---|
| `ashare_price19_repaired.csv` | Ridge、ENet、PLS、RF、GBRT 的实际模型指标 |
| `ashare_price19_repaired_extra.csv` | 同数据、同切分、同核心代码的 OLS、Lasso、PCR、NN3 补跑 |
| 两个 `manifest_*.json` | 样本数、配置窗口、特征、参数、环境和输入/源码哈希 |
| `monthly_summary/` | 48 月×9 模型的误差、IC、Rank IC，以及 pooled R² 重算校验 |
| `ridge_portfolio/`、`nn3_portfolio/` | 十分位组合月度毛收益与诊断；不含真实交易执行或费用 |
| `frozen_build.json`、`replay_comparison.json` | 冻结最终构建代码的独立全量重跑记录，确认模型输入与重建产物字节一致 |
| `entry_gate_audit.json` | 全文件60日入口条件的只读覆盖核查及来源哈希 |
| `feature_missingness/` | 19特征×训练/验证/测试的57行排名前缺失统计及输入绑定 |
| `executed_source/`、`source_annotation_revision.json` | 实际执行的builder字节副本，以及审查后仅修改模块说明的旧/新哈希和AST一致性；副本用于核查，不是独立执行入口 |

CSV 中模型表的 `IS/valid/OOS` 和其他 R² 字段以百分数计，例如 `1.090155` 表示 1.090155%。月度表中的 `r2_zero` 是原始比例，详见聚合 manifest 的单位说明。IC/Rank IC 是相关系数，不是百分收益。

相关系数汇总包含有效月份数：GBRT仅2025-05有效（1/48），其余47个月为截面常数预测；其他八模型两种相关系数均48/48有效。相关系数采用常数极差检查，避免相同小数的浮点标准差残差造成伪相关。

模型输入为 19 个特征，默认资格门槛是 24 个月形成期历史和当月至少 10 个交易日。虽然训练配置窗口为 2010–2018，实际训练目标月从 2012-01 起；验证 2019–2021，测试 2022-01—2025-12。建模股票月共 510,500，测试股票月 212,293。细节见 [新实验说明](../../docs/repaired_results.md)。

标签为未缩尾总收益，未减无风险收益；本次没有增加财报、行业哑变量或宏观交互。源数据 vintage、退市覆盖和公司行动完整性仍有局限。已有测试期间曾被多次查看，不能称为全新未触碰的留出期。

逐股预测和完整特征面板仅保存在本地，不进入本公开目录。公开的月聚合足以重算 pooled R²，但不能代替对逐股预测、原始数据和可交易性的完整审计。未保存每个候选配置的验证 MSE 和逐 epoch 轨迹；已保存选中参数、种子和最佳 epoch。
