# GKX 框架模拟复现与 A 股收益预测研究

作者：**Gilmour Jia**

本项目记录 Gu、Kelly 与 Xiu（2020，GKX）框架的模拟复现和 A 股扩展，包括六类机器学习方法、公开来源数据管道、特征扩展、历史实验以及数据和评估代码修订。它是持续改进的研究档案。

## 研究亮点及其证据状态

| 工作 | 已有内容 | 解释范围 |
|---|---|---|
| 模拟复现 | 线性/非线性 DGP、50/100 个基础特征、模型比较、变量选择和重要性 | 模拟结果与真实 A 股结果分开；部分单元偏离原文，保留偏离记录 |
| NN3 历史结果 | 样本外零基准 R² **1.0177149%（约 1.02%）**，152 列输入 | 历史成绩，受旧数据处理问题影响；不是本轮修复后已确认成绩 |
| 树模型比较 | RF、GBRT 在多个特征集和容量设定下的对照 | 保留不成功实验；不据此断言树模型普遍不适用于 A 股 |
| 数据与工程 | 行情、分红、财报、股本、行业和宏观信息的组合；标签与评估审计 | 已修代码不意味着源数据的历史版本、退市覆盖和可交易性已全部验证 |

六类方法为 PLS、PCR、Elastic Net、Random Forest、GBRT 和 Neural Networks。另列 OLS 基线、Ridge/Lasso 对照，以及模拟中的 Oracle/GLM。方法家族、模型变体和已完成实验数量分别登记，不能互换。

历史 NN3 的 1.02%、另一版本 Lasso 的 1.0517%、日志中的 Ridge 组合比率约 2.41，分别属于不同实验；详见证据清单。R² 是预测误差指标，不是投资收益率。新旧版本改变了数据处理、目标月边界和部分模型实现，不能把差值全部归因于一个修复。

## 修订后已运行的共同样本实验

使用相同的 19 个特征和未缩尾的下一自然月总收益，九个模型均在 212,293 个股票月、48 个目标月（2022–2025）上计分。下表为合并样本的零预测基准 R²；它们是同一历史测试期上的描述结果，没有显著性检验或新留出集的验证。

| 模型 | 样本外 R²（%） |
|---|---:|
| OLS | 1.0679 |
| Ridge | 1.0902 |
| Lasso | 0.8740 |
| Elastic Net | 0.7382 |
| PCR | 0.7591 |
| PLS | 1.1424 |
| RF | 0.7253 |
| GBRT | 0.1488 |
| NN3 | 0.8862 |

![修订后19特征模型的预测误差与排序指标](docs/figures/repaired_model_comparison.png)

图中括号为 Rank IC 的有效月份数。图仅展示点估计，没有置信区间；可用 `python scripts/plot_repaired_results.py` 从本库聚合CSV重新生成。

历史 NN3 的 **1.02%** 来自不同的 152 维实验；这里的 **0.8862%** 来自修订后的 19 特征实验，两者不能作为同条件修复前后比较。GBRT 在 47/48 个月的截面预测为常数，只有 2025-05 的 IC/Rank IC 有定义；不能把仅一个月的相关系数解释为整个测试期的排序能力。

完整面板在冻结构建源码后再次生成，与此前输出逐字节一致；九模型的 R² 已从逐股预测重算并与模型输出核对。当前 **36 项回归测试通过**。这些检查验证所列代码行为和结果计算，源数据历史版本及投资可执行性仍需补充审计。

## 最小运行

Python 3.12 是本次验证系列。建立自己的虚拟环境后运行：

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/run_smoke.py --nn
```

最小例子自动生成合成面板，运行 Ridge、RF、GBRT、NN1，不需要真实行情或 API 密钥。输出标为 `SYNTHETIC ONLY`，只验证工程流程，不能引用为 A 股实证结果。

## 使用自己有权访问的数据

原始数据不随本项目重新分发。先查看 [数据可用性说明](docs/data_availability.md) 和方法附录，准备日线、分红、股本及月收益等必要文件。以下 PowerShell 路径是需要用户替换的示例：

```powershell
$env:GKX_DATA_DIR = 'D:\research-data\gkx-raw'
$env:GKX_DERIVED_DIR = 'D:\research-data\gkx-repaired'
$env:GKX_OUT_DIR = 'D:\research-results\gkx-run-001'
python 'research/ML金融学习计划/D_A股数据/build_features.py'
python 'research/ML金融学习计划/D_A股数据/run_ashare.py' --models ridge,enet,pls,rf,gbrt --tag price19_run001
```

构建器读取原始目录，向派生目录写出修订面板。模型默认用 19 个价格、交易、股本和股息特征，以**未缩尾的下一自然月总收益**为标签；尚未转成扣除无风险利率的超额收益。默认按目标月训练 2010–2018、验证 2019–2021、测试 2022–2025，属于固定留出划分，未实现 GKX 的年度前推训练方案。

24 个月的历史资格要求使本次实际训练目标月从 2012-01 开始；有效训练为 2012–2018 的 84 个月。配置区间与实际进入估计的样本区间分别登记。

**入口兼容说明：** `run_ashare2.py` 和 `run_ashare3.py` 已改为共用 runner 的兼容入口，默认均为修订版 19 特征。文件名不再隐式启用旧 71/75 特征实验。扩展版本需要显式 `--chars` 和风险确认参数；它们不能被标注为已通过历史财报版本核验。完整参数见方法附录和 `--help`。

每次新实验使用新的输出目录和 `--tag`。输出包括模型指标、预测明细和运行 manifest，记录输入/源码哈希、参数、种子、依赖版本以及形成月和目标月。已有指标文件时 runner 拒绝相同 tag；这不是对全部残留文件的事务保护，部分文件存在或缺少最终 manifest 不代表完整成功运行，详见方法附录 F.2。逐股预测和大数据留在本地，公开结果仅发布明确选择的聚合统计。

## 当前解释边界
