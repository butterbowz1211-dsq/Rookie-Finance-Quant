# 后续改进重点与验收条件

作者：Gilmour Jia

本文件与研究报告分开维护。下面是未完成或需要更强证据的工作，不是已经取得的结果。历史测试期已被多次查看；本次路线图不是对过去实验的事前注册。

## 当前已推进的基础

本轮已经修订自然月标签、目标月时间隔离、收益缩尾污染、横截面排名、训练期行业词表以及部分模型实现，并加入针对性测试和独立新结果目录。具体修改和验证范围见 [数据修订](docs/data_bug_fixes.md) 与 [模型修订](docs/model_bug_fixes.md)。历史 1.02% 保留原始实验身份。

19 特征、固定目标月划分下的六类方法与 OLS/Ridge/Lasso 对照已全部运行，共九个模型，见 [修订后结果](docs/repaired_results.md)。月度损失、IC/Rank IC有效月份以及Ridge/NN3组合毛收益已导出；36项回归测试通过。下面涉及这些项目的工作指进一步扩展与验证，不把已完成的基础运行列为待办。

## 依赖顺序与具体验收

| 优先级 | 要回答的问题 | 需要做的工作 | 完成的判据 |
|---|---|---|---|
| P0 数据 | 所用收益是否反映持股者真实损益？ | 对收益尾部逐案核对分红、送转、配股、长停牌和上市首月；使用另一来源抽查；保存事件记录与差异原因 | 有逐项事件审计和复算结果；未解释异常不能被默认为正常，也不能为改善结果统一截尾 |
| P0 入口 | 逐股入口和缩尾参考池是否完全按当时信息构建？ | 移除冻结builder中的全文件少于60日入口条件；明确缩尾只使用预定当期参考池；完整重建与重估 | 保存样本和阈值差异；本次26只短历史股票虽无合资格月，也不假定加入后缩尾阈值或预测不变 |
| P1 缺失 | 长窗口特征的中性排名填补是否影响比较？ | 利用已公开57行分段缺失表，比较24/36个月资格、缺失指示与预定插补方案；控制相同样本 | 单独报告样本变化与处理变化；训练期mom36m缺失46.99%不被写成完整36月信号覆盖 |
| P0 数据 | 当时是否能获得每个财务/股本字段？ | 构建公告日、首次披露值、修订值及可用日期记录；补真实历史报表 vintage；核对股本变动公告日 | 每个特征能追到截至形成日可用的原始记录；无法恢复版本的特征维持探索性标签或排除 |
| P0 股票池 | 结论是否依赖幸存者和微盘股？ | 补退市股票、历史上市/ST状态、历史交易日历；保留退出时损益；事先定义基础池与排除最小市值30%池 | 每个月可重建当时股票池，并解释新增/退出；同模型分别报告两池结果，不能只展示较好者 |
| P1 复现 | 六类模型的比较能否扩展到经时点核验的财务面板？ | 保留已完成19特征共同样本实验；在财务历史版本核验后扩展同一面板的九模型比较；补存所有候选验证损失与NN逐epoch轨迹 | 每个模型能追到配置、全部候选、种子、数据/代码哈希及失败记录；预算差异明确披露 |
| P1 目标 | 总收益与超额收益结论有何差异？ | 获取可核验月度无风险利率，明确利率期限与月化方式；保留总收益平行对照 | 标签定义、利率来源、日期和单位写入 manifest；不混用两种目标的 R² |
| P1 训练 | 固定切分结果能否经受时间变化？ | 实现年度前推训练、滚动验证与年度预测；同时比较固定长度和扩展窗口 | 每个目标月仅被预测一次，训练/调参标签均已成熟；按年列样本量、误差与模型选择 |
| P1 推断 | 模型差异是否稳定，还是少数月份驱动？ | 在已有月度损失和IC/Rank IC上补分年分析及考虑序列相关的误差/区块重采样，处理多模型选择；扩展组合诊断到其余模型 | 同时报告效应大小与不确定性、逐年分解、极端月影响和有效月份；不把股票月行数当独立重复次数 |
| P1 泛化 | 经过反复试验后还能否预测新时期？ | 在调整完规则后冻结一个未来或从未用于开发的测试区间；记录开始条件和访问纪律 | 冻结前留存配置与哈希，首次评估后保留全部结果；不将现在的2022–2025期重新命名为未触碰样本 |
| P2 机制 | 模型增益来自流动性、动量、财务还是行业？ | 在相同样本上做特征组删除后重新训练；比较多窗口流动性；控制特征数量与调参预算 | 每个消融只改变规定因素；报告预测增量，预测重要性不宣称因果效应 |
| P2 树模型 | RF/GBRT的表现来自容量、信息集还是时期？ | 首先诊断本次GBRT在47/48个月常数预测的原因；系统检验叶节点样本、深度、子采样、树数、损失与时间窗口 | 保存训练/验证/测试损失、逐月预测唯一值及分布；在验证集选参，测试期不决定配置 |
| P2 神经网络 | 1.02%现象能否重复、何时出现？ | 在冻结数据上重复NN3，再比较NN1–NN5；记录每个种子、最佳epoch、集成误差和失败网络 | 展示所有预定种子与失败率，不只展示最佳种子；不得用另一模型的高分证明NN3无偏 |
| P2 经济意义 | 排序收益能否转成真实可执行组合？ | 先做可执行多头；加入次日成交、涨跌停、停牌、T+1、费用、滑点、容量；多空另核融券 | 订单、成交、现金、仓位、净值逐笔对账；毛收益与净收益、多头与多空分别报告 |
| P2 复现工程 | 新用户能否从合法输入重建结果？ | 数据schema验证、下载断点/错误分类、完整参数文件、环境锁定、最小例子和持续集成 | 新目录运行通过；路径可配置；缺数据/错字段失败明确；无需作者私有绝对路径 |
| P3 覆盖 | 还缺哪些原论文特征与模拟单元？ | 按逐项定义核对94特征、代理变量和未实现项；完成模拟重复数、期限和变量重要性缺口 | 提供一一映射的特征/模拟矩阵，明确完全实现、代理实现、未实现，避免只比较列数 |

## 新实验登记模板

每次新增实验至少保存：研究问题、输入文件和哈希、生成代码哈希、特征清单与版本、形成月/目标月、股票池规则、标签和无风险利率、训练/验证/测试边界、全部候选超参、选择准则、随机种子、最佳训练轮数、失败运行、依赖版本、命令、计分公式、输出文件清单及局限。

新实验报告需同时写“保持相同的条件”和“改变的条件”。当样本、目标或时间范围变化时，性能差异只能作为新设定的描述，不能归因为单一改动。

## 发布后的维护

优先修复会改变数据时点、标签或损益的错误，再补统计推断和现实执行，最后扩展模型数量与特征。每次会改变结论的修复都建立新版本，保留旧结果及撤回/修订说明。新增文献、代码或数据保留其原始作者和来源。
